# ROLLFORM

Светлая версия: https://looksawful.github.io/rollform/# · Тёмная версия: https://looksawful.github.io/rollform/dark/.
Каждая содержит пять страниц: главная, каталог, конструктор, корзина, контакты. Исходные компоненты общие; тема выбирается URL, а не настройкой ОС. Ссылки остаются внутри выбранной темы, корзина общая (один origin / localStorage).


Просмотровый прототип игральных костей. **Не магазин:** ни оплаты, ни отправки заявок продавцу; цены и реальные остатки не подтверждены.

Сайт: https://looksawful.github.io/rollform/ . Маршруты: /, /catalog/, /configure/, /cart/, /contacts/. Публичные тексты содержат только нейтральные заглушки; реквизиты и контакты ещё не предоставлены.

## Проверка
`npm ci` → `npm test` → `npm run typecheck` → `npm run build`.

## Единственный источник и публикация
`main` — рабочий код. `gh-pages` — **только** собранный `out/`, а не вторая ветка разработки. После push в `main` [GitHub Actions](.github/workflows/publish.yml) запускает тесты, TypeScript, статическую сборку с `NEXT_PUBLIC_BASE_PATH=/rollform` и публикует `out/` в `gh-pages`. При ошибке исправить CI, **не** редактировать статическую ветку вручную. Затем проверить пять маршрутов и CSS/JS.

До коммерческого запуска нужны подтверждённые товарные характеристики, продавец и канал фактического получения заявок, юридические условия. Без них сохранять явную пометку «демо». Внутренние решения и остаток QA ведутся в существующем трекере, не в новых документах.
