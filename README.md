# ROLLFORM

Светлая версия: https://looksawful.github.io/rollform/# · Тёмная версия: https://looksawful.github.io/rollform/dark/.
Каждая содержит шесть страниц: главная, каталог, конструктор, корзина, контакты, сроки изготовления. Исходные компоненты общие; тема выбирается URL, а не настройкой ОС. Ссылки остаются внутри выбранной темы, корзина общая (один origin / localStorage).


Просмотровый прототип игральных костей. **Не магазин:** ни оплаты, ни отправки заявок продавцу; цены и реальные остатки не подтверждены.

Сайт: https://looksawful.github.io/rollform/ . Маршруты: /, /catalog/, /configure/, /cart/, /contacts/, /production/. Часть текстов согласована для первого показа. Контакты и сроки без подтверждённых данных остаются явными заглушками; форма обратной связи не отправляет сообщения.

## Проверка
`npm ci` → `npm test` → `npm run typecheck` → `npm run build`.

## Единственный источник и публикация
`main` — рабочий код. `gh-pages` — **только** собранный `out/`, а не вторая ветка разработки. После push в `main` [GitHub Actions](.github/workflows/publish.yml) запускает тесты, TypeScript, статическую сборку с `NEXT_PUBLIC_BASE_PATH=/rollform` и публикует `out/` в `gh-pages`. При ошибке исправить CI, **не** редактировать статическую ветку вручную. Затем проверить шесть маршрутов в каждой теме и CSS/JS.

До коммерческого запуска нужны подтверждённые товарные характеристики, продавец и канал фактического получения заявок, юридические условия. До запуска не показывать фиктивные реквизиты и не выдавать форму/корзину за реальное оформление. Внутренние решения и остаток QA ведутся в существующем трекере, не в новых документах.

Код доступен для ознакомления: [LICENSE](LICENSE).

## Перед первым показом

Тексты корректируются по решениям пользователя от 05.11.2026. Bento отключён от главной,
но сохранён с ещё не проверенными заявлениями. Карточки показывают демонстрационные
варианты и три параметра: реальные остатки не подтверждены. Контакты без вымышленных
адресов, форма ничего не отправляет. Сроки изготовления и доставки ещё согласовываются.
Подробнее: [редакционный лог](docs/prototype-copy-draft.md) и
[Issue № 5](https://github.com/looksawful/rollform-internal/issues/5).
