# ROLLFORM

Просмотровый прототип игральных костей. **Не магазин:** ни оплаты, ни отправки заявок продавцу; цены и реальные остатки не подтверждены.

Сайт: https://looksawful.github.io/rollform/ . Маршруты: /, /configure/, /cart/. Главная и конструктор содержат нейтральные текстовые заглушки.

## Проверка
`npm ci` → `npm test` → `npm run typecheck` → `npm run build`.

## Единственный источник и публикация
`main` — рабочий код. `gh-pages` — **только** собранный `out/`, а не вторая ветка разработки. После push в `main` [GitHub Actions](.github/workflows/publish.yml) запускает тесты, TypeScript, статическую сборку с `NEXT_PUBLIC_BASE_PATH=/rollform` и публикует `out/` в `gh-pages`. При ошибке исправить CI, **не** редактировать статическую ветку вручную. Затем проверить три маршрута и CSS/JS.

До коммерческого запуска нужны подтверждённые товарные характеристики, продавец и канал фактического получения заявок, юридические условия. Без них сохранять явную пометку «демо». Внутренние решения и остаток QA ведутся в существующем трекере, не в новых документах.
