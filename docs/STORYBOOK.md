# Storybook

Run `npm install`, then `npm run storybook` (port 6006).

Run `npm run build-storybook` to validate the component catalog.

Stories render the real production components without changing the storefront runtime.
This initial catalog covers the cube outline and bento section; additional components
should be added with their real props, contexts, and responsive variants.

Added 2026-11-19 as part of the cross-repository UI inventory.
