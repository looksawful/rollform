## 3D-модель · исследование 04.11.2026

Только дизайн/проверка, не спецификация производства. Архитектуру `src/components/DiceViewer.tsx` + `src/lib/diceGeometry.ts` сохранять: Three.js с одним WebGL-рендерером, процедурная BufferGeometry и CanvasTexture; карточки каталога используют SVG. Текущие два вызова Viewer передают `interactive` без `autoRotate`, поэтому статичная сцена рисуется по необходимости. Это соответствует [Three.js Rendering on Demand](https://threejs.org/manual/pages/rendering-on-demand.html). Явное освобождение `geometry`, `material` и `texture` оставлять: [Three.js Disposing Objects](https://threejs.org/manual/pages/how-to-dispose-of-objects.html).

**Приоритеты перед превращением в реальные игральные кости:**
1. P1, игровая нумерация: сейчас `faceLabel('d4')` даёт одно число на каждую из четырёх граней, но после броска одна грань скрыта, а три видимые различаются: результат нельзя однозначно считать без утверждённой «top-point» или «base» разметки. `d10` сейчас 1–10, тогда как обычно 0–9; `d%` уже 00–90. D8/D12/D20 получают произвольный порядок по индексам граней, не утверждённые противоположные пары. Сначала выбрать схему разметки с владельцем товара и добавить тест противоположных пар + ручной визуальный осмотр. Источники: [производитель MAGISEVEN, схемы D4/D10 и суммы](https://www.magiseven.com/en-ca/blogs/news/the-right-dnd-dice-numbering-convention), [исследование вариантов D20](https://www.aleakybos.ch/Configurations.htm). Единственного стандарта полной перестановки D20 нет, не навязывать один.
2. P2, шрифт: Inter загружается CSS `@import`, но `CanvasTexture` растеризует цифры немедленно. После применения реального шрифта ждать `document.fonts.load('700 156px Inter')` перед первой генерацией CanvasTexture либо перерисовать текстуры при событии загрузки; проверить холодную загрузку. [MDN CSS Font Loading API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Font_Loading_API).
3. P2, физический предмет: текущие острые грани, светлые контурные линии и плоские текстовые таблички не моделируют фаску/скругление/гравировку. Сначала утвердить облик реального кубика. Для D6 возможен штатный [RoundedBoxGeometry](https://threejs.org/docs/pages/RoundedBoxGeometry.html); для других форм его нельзя использовать автоматически. После bevel потребуется отдельно пересчитать центры и нормали граней.
4. P3, motion: в текущем UI автоповорот и scroll-motion не используются. Не вводить R3F, OrbitControls, GSAP, инерцию, физику и постпроцессинг только ради абстракции. При возврате автодвижения скорость должна использовать `deltaTime`; пока нет запроса на motion, проще удалить неиспользуемые параметры при следующем целевом изменении.
5. P3, производительность/контроль: D20 создаёт 20 отдельных CanvasTexture 256² (порядка 5 MiB сырых RGBA-пикселей без GPU overhead). Не строить texture atlas до профилирования `renderer.info` и реального FPS. `touch-action:pan-y` позволяет браузеру перехватывать вертикальную прокрутку и вызывать `pointercancel`; проверить на настоящем Safari/Chrome. Источники: [Three.js CanvasTexture](https://threejs.org/manual/pages/canvas-textures.html), [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action).
